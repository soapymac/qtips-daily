# Image credits

Stock photos are **not** bundled in this repo. Add your own to `public/images/`
using the filenames below, then record the source and licence here and in
`src/lib/images.ts` (the `credit` / `creditUrl` fields render a small caption
on the image when set).

Rules from the brief:

- Tasteful, professional outdoor / grounds imagery only.
- Credit where the licence requires it (most free stock sites appreciate it even
  when not required).
- Never present a photo of a real, named person as JD Grounds staff.
- Until a file is added, each slot shows a built-in illustration instead, so the
  site never shows a broken image.

| Slot       | File                        | Suggested subject                                   | Source | Licence | Credit |
| ---------- | --------------------------- | --------------------------------------------------- | ------ | ------- | ------ |
| `hero`     | `public/images/hero.jpg`    | Freshly striped commercial lawn with hedge / trees  |        |         |        |
| `services` | `public/images/services.jpg`| Ride-on mower on a wide lawn, no identifiable faces |        |         |        |
| `about`    | `public/images/about.jpg`   | Cornish fields or coast, green and open             |        |         |        |
| `areas`    | `public/images/areas.jpg`   | South Cornwall harbour village (Charlestown, Mevagissey, Fowey) |  |  |        |

Recommended size: 1600 × 1200 px, JPEG quality ~80, under 250 KB each.

Good free sources: Unsplash (unsplash.com/license), Pexels (pexels.com/license),
Pixabay. Check each photo's licence page before use.
